Auth: ทุก request ต้องใส่ Authorization: Bearer {{token}}
1
GET All Users
เริ่มได้เลย
▼
ดึงรายการ user ทั้งหมด เช็ค array structure และ field ให้ครบ เหมือน GET list ในงานจริง
ตั้งค่า Request
Method: GET
URL: {{baseUrl}}/users
Header: Authorization: Bearer {{token}}
Response ที่จะได้
[ { "id": 7053240, "name": "Abhimanyu Agarwal", "email": "abhimanyu@example.com", "gender": "male", "status": "active" }, ... ]
โจทย์
1
เช็ค status 200
2
เช็คว่า response เป็น array
3
เช็คว่า array ไม่ว่าง
4
เช็คว่า object อันแรกมี field id, name, email, gender, status
5
เช็ค type: id เป็น number, name เป็น string
6
เช็คว่า status เป็น "active" หรือ "inactive" เท่านั้น
7
เช็คว่า email มี @ อยู่ด้วย
8
บันทึก id อันแรกไว้ใน collectionVariables ชื่อ userId
